# ENCORE 티켓팅 디자인 시안

콘서트 티켓팅 서비스의 화면과 예매 흐름을 확인하는 정적 프로토타입이다.
Node.js 내장 기능만 사용하므로 패키지 설치가 필요 없다.

## 로컬 실행

Node.js 20.11 이상에서 레포지토리 루트 기준으로 실행한다.

```bash
git clone https://github.com/Good-Ticket-Service/ticket-frontend.git
cd ticket-frontend
npm run dev
```

브라우저에서 http://127.0.0.1:4173 으로 접속한다. 종료하려면 `Ctrl+C`를 누른다.

```bash
npm run check
```

## 화면 흐름

메인 → 공연 상세·회차 선택 → 좌석 선택 → 예매 확인·모의 결제 → 예매 완료 → 나의 티켓

검색, 카테고리 필터, 찜하기, 메인 포스터 전환, 다크 모드, 최대 4개 좌석 선택,
등급별 가격 계산, 5분 선택 타이머, 결제 수단 전환, 입력값 검증, 완료 효과를 제공한다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `public/index.html` | 문서와 공통 레이아웃 |
| `public/style.css` | 반응형 화면과 애니메이션 |
| `public/app.js` | 샘플 공연 데이터와 화면 전환·인터랙션 |
| `preview.mjs` | 로컬 정적 파일 서버 |

## 데이터와 연동 범위

백엔드 API, 로그인, 실제 좌석 선점, 결제 PG는 연동하지 않았다.
공연·좌석·선점 타이머는 브라우저에서 동작하는 시뮬레이션이다.
예매 결과는 현재 브라우저의 `localStorage`에 `encore-bookings` 키로 저장한다.
입력한 예매자 이름·이메일은 저장하거나 서버로 전송하지 않는다.
찜한 공연과 테마는 새로고침하면 초기화된다.
발급되는 티켓과 바코드는 입장에 사용할 수 없는 디자인 요소다.

글꼴은 Google Fonts에서 로드하며, 네트워크 연결이 없으면 시스템 글꼴을 사용한다.
이 소스에는 자동 배포 설정이 없다.
